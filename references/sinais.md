# Sinais de texto com cara de IA em português do Brasil

Use na reescrita. É uma lista de estilo: serve para dizer "não quero que a minha prosa soe assim". Nenhum sinal isolado prova quem escreveu.

## Estrutura (consertar sempre)

| Sinal | Como aparece | Conserto |
|---|---|---|
| Contraste de molde | "Não é X, é Y", "Não vendemos X. Vendemos Y.", "Mais do que X, é Y", "X? Não. Y." | Afirme Y direto |
| Terceira opção forçada | "Não é nem A, nem B. É C." | Diga C com um fato |
| Fecho de efeito | "E isso muda tudo.", "Simples assim.", "É sobre isso." | Corte. Termine na informação |
| Aforismo solto | "Tempo é amor em movimento.", "Cuidar também é deixar ir." | Troque por um caso ou corte |
| Trio vazio | "Estruturado. Testado. Escalado." | Dois itens com concreto, ou quatro |
| Ritmo picado | Três ou mais frases seguidas com até quatro palavras | Junte com "e", "mas", "porque", "quando" |
| Lista de funcionalidades como frase | "Lê, avalia, reescreve, checa e publica" | Escolha o que importa e conte |
| Esquema de slide | "O problema: X. O conserto: Y." | Escreva em prosa |
| Pigarro antes de falar | "A questão é a seguinte:", "A verdade é que", "Vamos ser sinceros", "Vale ressaltar que", "É importante destacar", "Cabe salientar" | Comece no assunto |
| Pergunta de suspense | "O segredo?", "Resultado?", "Curioso?", "E agora?" | Afirme |
| Dono de frase vaga | "Especialistas apontam", "Estudos mostram" | Nomeie a fonte que o texto já tinha, ou peça. Sem fonte, marque |
| Qualificador universal | "para qualquer negócio, qualquer nicho" | Diga para quem serve |
| Analogia batida | "É como ter uma Ferrari e não saber dirigir" | Use caso real ou corte |
| Entusiasmo de sistema | "Estamos muito felizes em", "Novidade empolgante!" | Dê a notícia |
| Travessão | `—` ou `–` em texto corrido | Vírgula, ponto, dois-pontos ou parênteses |
| Negrito em tudo | Mais de um destaque por parágrafo | Fique com um, onde você daria ênfase em voz alta |

## Aberturas e fechamentos

Abertura ruim: "No mundo de hoje", "Num mundo cada vez mais", "Na era digital", "Vivemos um momento em que", "Você já se perguntou", "Imagine por um instante", "Descubra o poder de", "Não é segredo para ninguém". Comece pelo caso, pelo número ou pela frase que a pessoa diria em voz alta.

Fechamento ruim: "Em conclusão", "Em suma", "Espero que este conteúdo tenha sido útil", "Conta nos comentários", "O futuro pertence a quem", "No fim das contas", "Agora é com você". O último parágrafo entrega a última informação e para.

## Metáforas traduzidas e palavras de consultoria

| Evite | Prefira |
|---|---|
| desbloquear, destravar (potencial, crescimento) | diga o que passa a acontecer |
| alavancar | usar, aproveitar |
| impulsionar | aumentar, acelerar |
| elevar, levar ao próximo nível | diga o quanto melhora |
| navegar pelas complexidades | lidar com |
| papel fundamental, peça-chave, divisor de águas | diga o que mudou; sem o dado, corte o enfeite |
| mergulhar fundo | estudar, examinar |
| jornada, ecossistema (fora do sentido literal) | processo, mercado, ou o nome real |
| otimizar | melhorar, ajustar |
| viabilizar | permitir |
| mitigar | reduzir |
| robusto, abrangente | forte, completo, ou o número |
| proativo, assertivo | antecipado, direto |
| potencializar | aumentar |
| holístico, disruptivo, sinergia, paradigma | diga o que é, na prática |
| engajamento, entregar valor | diga o que a pessoa fez ou ganhou |

Palavra técnica usada no sentido técnico fica ("servidor robusto a falhas" numa documentação de engenharia).

## Conectivos

"Além disso", "No entanto", "Consequentemente", "Nesse sentido", "Dito isso", "Por outro lado", "Contudo", "Portanto". Nenhum é errado sozinho; o problema é um por parágrafo. Prefira "e", "mas", "por isso", "só que", ou corte.

## Tetos

| Item | Limite |
|---|---|
| Conectivo da lista | 1 a cada 3 frases |
| Adjetivo de entusiasmo (incrível, poderoso, essencial, revolucionário) | 1 a cada 500 palavras |
| Trio de itens paralelos | 1 por texto |

## Outros tiques

- Cadeia de gerúndios ("destacando, enfatizando, demonstrando").
- Verbo inflado no lugar de "é": "serve como", "atua como", "figura como".
- Trocar a palavra só para não repetir. Se o assunto é "prompt", escreva "prompt".
- Palavras de Portugal num texto brasileiro: facto, perspetiva, monitorizar, partilhado.
- "Fulano entendeu que...", "Isso tem nome:".
